## Root cause of the biome-teleport collapse (3-4 fps)

GPU VRAM exhaustion, not JS heap. Terrain chunk textures (~16.8MB each) linger ~14s after teleport (EVICT_AFTER_FRAMES=600 + sweep/256 frames); rapid biome-hops pile up 300-500MB stale VRAM -> driver thrash. Compounded by ~30 unbounded per-biome caches (image Maps, GL textures, canvases) that never evict on scene change, + hundreds of small_flora 404s per teleport. See finding #1 + the leak group.
