5815| # Terrain Rendering Cleanup — Design Spec
5816| 
5817| **Date:** 2026-05-31
5818| **Status:** Draft
5819| **Goal:** Strip the rendering pipeline down to what works, rebuild terrain rendering using Godot-native TileMapLayer patterns that match standard 2D RPG tutorials.
5820| 
5821| ## Problem Statement
5822| 
5823| The current codebase has ~1500 lines of competing rendering systems:
5824| - **TileMapTerrainRenderer** renders base terrain via TileMapLayer `set_cell()`
5825| - **ElevationRenderer** renders elevation as Image-based Sprite2D overlays using terrain_v3 tiles
5826| - These use **different art assets** (v3 vs v4), **different rendering methods**, and **fight for the same screen space**
5827| - Elevation is invisible despite code running — the Y-offset stacking approach doesn't produce visible results
5828| - Transition tiles between surfaces are broken (manual wang computation is error-prone)
5829| - All layers are created dynamically in code — invisible in the Godot editor Scene panel
5830| 
5831| ## Design Principles
5832| 
5833| 1. **Use Godot the way it was designed.** TileMapLayer nodes in the scene tree. `set_cells_terrain_connect()` for auto-tiling. Terrain sets with peering bits.
5834| 2. **One rendering system, not two.** No Image-based overlays competing with TileMapLayers.
5835| 3. **Visible in the editor.** All layers exist as nodes in the `.tscn` file. Clickable, inspectable, toggleable.
5836| 4. **Standard 2D RPG elevation.** Cliff wall tiles at elevation drops. Shading overlays. Surface changes via gradient table. No Y-offset stacking.
5837| 5. **Preserve what works.** Overmap → ChunkCompiler → ChunkStreamer pipeline untouched. terrain_v4 tilesets reused. Day/night cycle kept.
5838| 
5839| ## Architecture
5840| 
5841| ### Chunk Size: 16×16
5842| 
5843| Changed from 64×64. This makes `set_cells_terrain_connect()` fast (~1ms per call vs multi-second hangs at 64×64). Grid radius increases from 3 to 8 (17×17 grid = 289 chunks) to maintain the same visible area.
5844| 
5845| ### Scene Tree Structure
5846| 
5847| ```
5848| CleanWorld (Node2D)
5849|   ├── TileMap (Node2D, y_sort_enabled=false)
5850|   │   ├── TerrainLayer    (TileMapLayer, z_index=-2)
5851|   │   ├── CliffLayer      (TileMapLayer, z_index=-1)
5852|   │   ├── ShadingLayer    (TileMapLayer, z_index=-1)
5853|   │   ├── WaterLayer      (TileMapLayer, z_index=0)
5854|   │   ├── RoadLayer       (TileMapLayer, z_index=2)
5855|   │   ├── BuildingLayer   (TileMapLayer, z_index=3)
5856|   │   └── RoofLayer       (TileMapLayer, z_index=8)
5857|   ├── Player (CharacterBody2D)
5858|   │   └── Camera2D
5859|   ├── DayNightCycle
5860|   └── UI (CanvasLayer)
5861| ```
5862| 
5863| All TileMapLayer nodes share a single TileSet resource built by TerrainTilesetBuilder at startup. The TileMap parent node exists for organizational grouping — it is NOT a TileMap node, just a Node2D.
5864| 
5865| These nodes are defined in the `.tscn` file (visible in editor). The TileSet is assigned programmatically at startup since it's built from terrain_v4 assets.
5866| 
5867| ### Layer Definitions
5868| 
5869| | Layer | z_index | Content | Populated By |
5870| |-------|---------|---------|-------------|
5871| | TerrainLayer | -2 | Base biome tiles (lush_grass, golden_sand, etc.) with auto-tiled transitions | `set_cells_terrain_connect()` per terrain_id |
5872| | CliffLayer | -1 | Cliff face tiles at elevation tier boundaries | Manual `set_cell()` at tier drops ≥ 2 |
5873| | ShadingLayer | -1 | Semi-transparent dark/light overlays for hillshade | Manual `set_cell()` based on slope/elevation |
5874| | WaterLayer | 0 | Ocean, river, lake tiles | `set_cells_terrain_connect()` for water terrain |
5875| | RoadLayer | 2 | Dirt/cobblestone road tiles | Manual `set_cell()` from road_cells |
5876| | BuildingLayer | 3 | Wall, floor, door tiles | Manual `set_cell()` from building_tiles |
5877| | RoofLayer | 8 | Roof canopy (alpha-fades when player enters) | Manual `set_cell()` from structure bounds |

5879| ### Terrain Rendering Flow
5880| 
5881| ```
5882| ChunkData compiled (elevation, biome, ocean)
5883|     │
5884|     ▼
5885| ElevationGradientTable.surface_at(biome, elevation) → surface_id per tile
5886|     │
5887|     ▼
5888| Group tiles by terrain_id (from TerrainTilesetBuilder)
5889|     │
5890|     ▼
5891| For each terrain_id:
5892|     set_cells_terrain_connect(cells, 0, terrain_id)
5893|     │
5894|     ▼
5895| Godot auto-selects correct tile from:
5896|   - Self-tilesets (13 surfaces: lush_grass, snow, etc.)
5897|   - Transition tilesets (19 pairs: golden_sand↔lush_grass, etc.)
5898|   - Void-edge tilesets (12 surfaces: for cliff edges)
5899|   using peering bits configured in TerrainTilesetBuilder
5900| ```
5901| 
5902| ### Elevation Visualization
5903| 
5904| Elevation is shown through THREE visual cues (standard 2D RPG approach):
5905| 
5906| 1. **Surface changes** — The gradient table maps higher elevation to different surfaces (grassland: lush_grass → dry_grass → grey_rock → snow). This already works.
5907| 
5908| 2. **Cliff wall tiles** — On the CliffLayer, cliff face tiles are placed where elevation drops ≥ 2 tiers. Uses solid brown/dark cliff tiles from `_add_shading_and_cliff_sources()`. Only at sustained boundaries (≥3 of 5 horizontal neighbors must also have a cliff drop — filters noise).
5909| 
5910| 3. **Shading overlay** — On the ShadingLayer, semi-transparent tiles darken valleys and NW-facing slopes. Subtle but adds depth perception.
5911| 
5912| No Y-offset stacking. No overlapping Sprite2D images. No separate elevation renderer.
5913| 
5914| ### Elevation Tier System
5915| 
5916| ```
