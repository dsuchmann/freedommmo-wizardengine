# PixelLab Dual-Grid Wang Tile Mapping

## Overview

PixelLab's `create_topdown_tileset` generates **16 tiles** in a **dual-grid corner-based** system.
Each tile encodes which of the **4 corners** (NW, NE, SW, SE) belong to biome A vs biome B.

For a tileset named `A_to_B`:
- **Biome A** = the "from" biome (first in name)
- **Biome B** = the "to" biome (second in name)

## Spritesheet Layout

The 16 tiles are arranged in a 4x4 grid (128x128px total, each tile 32x32):
```
Row 0: wang_0  wang_1  wang_2  wang_3
Row 1: wang_4  wang_5  wang_6  wang_7
Row 2: wang_8  wang_9  wang_10 wang_11
Row 3: wang_12 wang_13 wang_14 wang_15
```

## Per-Tile Corner Descriptions

B = biome B ("to"), A = biome A ("from")

```
Wang  | NW  NE  SW  SE | Corner Mask | Description
------|----------------|-------------|----------------------------------
  0   |  A   A   B   A |   0010 = 2  | B outer corner SW
  1   |  A   B   A   B |   0101 = 5  | B right edge (NE+SE)
  2   |  B   A   B   B |   1011 = 11 | A inner corner NE (B everywhere except NE)
  3   |  A   A   B   B |   0011 = 3  | B bottom edge (SW+SE)
  4   |  B   A   A   B |   1001 = 9  | B diagonal NW+SE
  5   |  A   B   B   B |   0111 = 7  | A inner corner NW (B everywhere except NW)
  6   |  B   B   B   B |   1111 = 15 | ALL B (interior biome B)
  7   |  B   B   B   A |   1110 = 14 | A inner corner SE (B everywhere except SE)
  8   |  A   B   A   A |   0100 = 4  | B outer corner NE
  9   |  B   B   A   A |   1100 = 12 | B top edge (NW+NE)
 10   |  B   B   A   B |   1101 = 13 | A inner corner SW (B everywhere except SW)
 11   |  B   A   B   A |   1010 = 10 | B left edge (NW+SW)
 12   |  A   A   A   A |   0000 = 0  | ALL A (interior biome A)
 13   |  A   A   A   B |   0001 = 1  | B outer corner SE
 14   |  A   B   B   A |   0110 = 6  | B anti-diagonal NE+SW
 15   |  B   A   A   A |   1000 = 8  | B outer corner NW
```

## Lookup Table: Corner Bitmask → Wang Index

```javascript
// Bitmask: NW=bit3(8), NE=bit2(4), SW=bit1(2), SE=bit0(1)
// 1 = biome B ("to"), 0 = biome A ("from")

const CORNER_TO_WANG = [
  12,  // 0b0000 (0)  = all A           → wang 12
  13,  // 0b0001 (1)  = B_SE            → wang 13
   0,  // 0b0010 (2)  = B_SW            → wang  0
   3,  // 0b0011 (3)  = B_SW+SE (bot)   → wang  3
   8,  // 0b0100 (4)  = B_NE            → wang  8
   1,  // 0b0101 (5)  = B_NE+SE (right) → wang  1
  14,  // 0b0110 (6)  = B_NE+SW (anti)  → wang 14
   5,  // 0b0111 (7)  = B_NE+SW+SE      → wang  5
  15,  // 0b1000 (8)  = B_NW            → wang 15
   4,  // 0b1001 (9)  = B_NW+SE (diag)  → wang  4
  11,  // 0b1010 (10) = B_NW+SW (left)  → wang 11
   2,  // 0b1011 (11) = B_NW+SW+SE      → wang  2
   9,  // 0b1100 (12) = B_NW+NE (top)   → wang  9
  10,  // 0b1101 (13) = B_NW+NE+SE      → wang 10
   7,  // 0b1110 (14) = B_NW+NE+SW      → wang  7
   6,  // 0b1111 (15) = all B           → wang  6
];
```

## Usage in Game Engine

```javascript
/**
 * Get the wang tile index for a transition between two biomes.
 * 
 * In dual-grid, each TRANSITION tile sits at the intersection of
 * 4 map cells. The 4 corners correspond to the biomes of those
 * 4 adjacent cells.
 * 
 * @param {string} nwBiome - biome of the NW cell
 * @param {string} neBiome - biome of the NE cell
 * @param {string} swBiome - biome of the SW cell
 * @param {string} seBiome - biome of the SE cell
 * @param {string} toBiome - the "to" biome in the tileset name
 * @returns {number} wang tile index (0-15)
 */
function getWangTileIndex(nwBiome, neBiome, swBiome, seBiome, toBiome) {
  const mask = 
    (nwBiome === toBiome ? 8 : 0) |
    (neBiome === toBiome ? 4 : 0) |
    (swBiome === toBiome ? 2 : 0) |
    (seBiome === toBiome ? 1 : 0);
  return CORNER_TO_WANG[mask];
}

// Example: beach_to_river tileset
// 4 map cells around an intersection: NW=river, NE=river, SW=beach, SE=river
// toBiome = "river" (second in tileset name)
// mask = (0 | 0 | 0 | 0) = 0 → CORNER_TO_WANG[0] = 12 → wang_12 (all river interior)

// Another: NW=beach, NE=river, SW=beach, SE=beach  
// mask = (8 | 0 | 2 | 1) = 11 → CORNER_TO_WANG[11] = 2 → wang_2 (river inner corner NE)
```

## Key Insight: Dual-Grid Offset

The transition tile grid is **offset by half a tile** from the biome cell grid:

```
Biome grid:          Transition grid (offset):
+---+---+---+        +---+---+
| A | A | B |      / | t | t |
+---+---+---+    /   +---+---+
| A | B | B |   /    | t | t |
+---+---+---+        +---+---+

Each transition tile 't' sits at the corner where 4 biome cells meet.
Its 4 corners sample the 4 adjacent biome cells.
```
