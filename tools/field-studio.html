Field Studio

Variants view: one tile per base variant (states & animations are NOT shown — they follow the base automatically). Click a tile to OMIT (red) → its base + states + anims are all excluded. Each object also has an omit whole object button. Keys: ←↑↓→ move · space omit · 1-6 tag · n note. Autosaves; Export when done.

Objects view: one tile per object — click to OMIT the WHOLE object (every variant + its states & anims). Amber = partially omitted. Double-click an object (or use View) to drill into its variants.
