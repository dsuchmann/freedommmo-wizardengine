Window Tiling Preview

This renders a synthetic building through the real drawBuildingTiles() from src/render/building-tiles.js — same wall mirror-tiling, same per-storey aperture overlay as the game — but deterministically: fixed camera, no day-night tint, no CRT, no load-race. Floor 0 uses ground_window (with the foundation course); every floor above uses upper_window (foundation-free). The amber floor lines mark each storey boundary so you can see how the upper-window's top cap meets the wall above it.
